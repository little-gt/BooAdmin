# BooAdmin テーマ for Typecho

> 🌐 言語：[中文](README.md) · [English](README.EN.md) · [日本語](README.JA.md.md)

> **効率的 · モダン · ミニマル**

## ⚙️ インストールとアップグレード

> ⚠️ 重要：
> 管理バックエンドに関わる操作については、作業前にサイトのデータベースと `admin` ディレクトリのバックアップを推奨します。展開中はバックエンドを更新しないでください。ブラウザの読み込みが不完全になったり、古い静的リソースファイルが誤って保存されたりするのを防ぐためです。

### 新規インストール

1. [最新のリリース](https://github.com/little-gt/BooAdmin/releases) をダウンロードします。
2. アーカイブを展開します。
3. 展開して得られた `admin` フォルダを Typecho サイトのルートディレクトリにアップロードし、既存の `admin` ディレクトリを**上書き**します。
4. 管理画面にログインし、新しい BooAdmin をお楽しみください。

### 旧バージョンからのアップグレード

1. **強く推奨**：サーバー上の古い `admin` ディレクトリを削除します。
2. 最新版の `admin` ディレクトリをサイトのルートにアップロードし、展開します。
3. Typecho 1.3.0 以降をご利用の場合、アップグレード後すべての機能が自動的に適応します。
4. モバイルから管理ページにアクセスすると自動的にカードビューに切り替わり、PC 側はテーブルビューのままです。

## 🧱 技術スタック

### フロントエンドフレームワークとスタイル

| コンポーネント | リソース | バージョン | 説明 |
| ---- | ---- | ---- | ---- |
| フォント | Google Fonts | Sans Serif 系 | 中国語・英語フォントの読み込みに使用 |
| アイコンライブラリ | FontAwesome | 7.2.0 | テーマ内のカスタムアイコンの読み込みに使用 |
| チャートライブラリ | ECharts.js | 5.5.0 | ダッシュボードのチャートに使用 |
| プログレスバー | NProgress | 0.2.0 | テーマ内のプログレスバーに使用 |
| 数式描画 | KaTeX | 0.16.38 | 投稿プレビュー機能の数式レンダリングに使用 |
| CSS フレームワーク | TailwindCSS | 4.4.3（3.4.17 互換）| テーマのスタイルシステムの構築に使用。ビルド設定は [config/README.md](config/README.md) 参照 |

| 項目 | 説明 |
| ---- | ---- |
| CDN 提供者 | GARFIELDTOM'S NEST CDN（中文名：懒猫小站静的リソース配信システム） |
| 配信範囲 | BooAdmin が依存する JavaScript、CSS、フォント、アイコンなどの静的リソースライブラリ |
