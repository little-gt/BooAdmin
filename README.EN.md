# BooAdmin Theme for Typecho

> 🌐 Language：[中文](README.md) · [日本語](README.JA.md)

> **Efficient · Modern · Minimal**

A modernized Typecho admin theme rebuilt with TailwindCSS. Fully compatible with Typecho 1.3.0, and accelerated via GARFIELDTOM'S NEST CDN for stable and efficient resource delivery.

## ⚙️ Installation & Upgrade

> ⚠️ Important:
>
> For any operation involving the admin backend, we recommend backing up your website database and the `admin` directory beforehand. During extraction, do not refresh the admin panel, to avoid incomplete browser loading or incorrectly saving stale static resource files.

### Fresh Install

1. Download the [latest Release](https://github.com/little-gt/BooAdmin/releases).
2. Extract the archive.
3. Upload the extracted `admin` folder to the root directory of your Typecho site, **overwriting** the existing `admin` directory.
4. Log in to the admin panel and enjoy the new BooAdmin.

### Upgrade from an Older Version

1. **Strongly recommended**: delete the old `admin` directory on the server.
2. Upload and extract the latest `admin` directory to the site root.
3. If you are using Typecho 1.3.0 or later, all features will adapt automatically after the upgrade.
4. Mobile access to the admin pages will automatically switch to a card view; the PC side keeps the table view.

## 🧱 Tech Stack

### Frontend Frameworks & Styles

| Component | Resource | Version | Description |
| ---- | ---- | ---- | ---- |
| Font | Google Fonts | Sans Serif family | Used to load Chinese and English fonts |
| Icon Library | FontAwesome | 7.2.0 | Used to load custom icons within the theme |
| Chart Library | ECharts.js | 5.5.0 | Used for the dashboard charts |
| Progress Bar | NProgress | 0.2.0 | Used for the progress bar within the theme |
| Formula Rendering | KaTeX | 0.16.38 | Used for formula rendering in the post preview feature |
| CSS Framework | TailwindCSS | 4.4.3 (compatible with 3.4.17) | Used to build the theme's style system; see [config/README.md](config/README.md) for build config |

### Resource Acceleration

| Item | Description |
| ---- | ---- |
| CDN Provider | GARFIELDTOM'S NEST CDN (Chinese name: Lazy Cat Station Static Resource Distribution System) |
| Distribution Scope | Static resource libraries such as JavaScript, CSS, fonts, and icons that BooAdmin depends on |
| Access Point | [https://cdn.garfieldtom.cool](https://cdn.garfieldtom.cool) |
